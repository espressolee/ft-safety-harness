# Repository contract

This repository is the canonical source for the generic dynamic validation
runner. Keep package-specific reproducers, private advisories, manuscripts,
and credentials out of it.

Before committing, run `python3 scripts/qualify_release.py`. A clean local
qualification does not establish a published release, remote CI, external
adoption, root cause, or security severity. Do not push, tag, publish, or open
a pull request without the owner's explicit approval.
